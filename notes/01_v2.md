# Linear Algebra Foundations: Tensors, Matrix Operations, Eigenvalues, SVD

## 1. TL;DR / Executive Summary

- **Scalars, Vectors, Matrices, and Tensors** are the fundamental data structures of linear algebra. A scalar is a single number, a vector is a 1D list of numbers, a matrix is a 2D grid, and a tensor is the general $n$-dimensional grid.
- **Vectors as Arrows / Matrices as Functions**: Geometrically, vectors are arrows in space. A matrix is a mathematical machine (a linear function) that takes an input arrow, stretches and rotates it, and outputs a new arrow.
- **Matrix Multiplication** is function composition. When you multiply $C = AB$, you are applying the transformation $B$ followed by the transformation $A$. It is not commutative ($AB \neq BA$).
- **Norms and Inner Products**: Norms measure the "length" or "size" of a vector or matrix. Inner (dot) products measure how aligned two vectors are.
- **Orthogonality** means two vectors are perpendicular (their dot product is zero). Orthogonal matrices are transformations that perfectly preserve lengths and angles (pure rotations/reflections).
- **Eigenvalues and Eigenvectors**: When a matrix transforms a space, some special vectors (eigenvectors) only get stretched or shrunk, not rotated. The stretch factor is the eigenvalue. They represent the "principal axes" of the matrix's behavior.
- **Singular Value Decomposition (SVD)**: The most important theorem in applied linear algebra. It states that *any* matrix, no matter its shape, can be factored into a rotation, a stretch along the axes, and another rotation ($A = U\Sigma V^\top$).

## 2. Why This Topic Matters

Linear algebra is the physics engine of machine learning. It is not just a prerequisite; it is the language in which all modern deep learning is written.

- **Data Representation**: Every piece of data—text tokens, pixels, audio waveforms—is embedded into a vector. A batch of data is a matrix. A sequence of batches over time is a tensor.
- **Neural Network Layers**: A standard feed-forward layer (`nn.Linear` in PyTorch) is just a matrix multiplication $y = xW^\top + b$.
- **Attention Mechanisms**: In Transformers (the architecture behind LLMs), attention is computed as $\text{softmax}(QK^\top/\sqrt{d_k})V$. This is pure matrix multiplication. Understanding why we transpose $K$ and how we multiply these matrices is critical.
- **Backpropagation**: The chain rule in deep learning is implemented using vector-Jacobian products. The transpose rule $(AB)^\top = B^\top A^\top$ is why gradients flow backwards with transposed weight matrices.
- **Model Compression and LoRA**: SVD proves that we can approximate large matrices with the product of two smaller ones. Low-Rank Adaptation (LoRA) uses this exact property to fine-tune 70-billion-parameter LLMs on consumer GPUs by only learning a low-rank update matrix $\Delta W = BA$.
- **Dimensionality Reduction**: Principal Component Analysis (PCA) is mathematically equivalent to computing the SVD of a centered data matrix.

If you don't understand linear algebra, deep learning will forever look like a black box of magic API calls. Once you understand it, a neural network is just a series of geometric transformations.

## 3. Prerequisites and Mental Models

### Prerequisites
- **Basic Algebra**: You should understand variables, functions $f(x)$, and basic equations like $y = mx + b$.
- **Basic Programming**: Familiarity with arrays/lists in any language (e.g., Python `[1, 2, 3]`).

### Mental Models
1. **The Data Structure Model (The Engineer's View)**:
   - Scalar = `float`
   - Vector = `List[float]` (1D array)
   - Matrix = `List[List[float]]` (2D array)
   - Tensor = Multidimensional array.
   You access a vector element with `v[i]`, a matrix element with `M[i][j]`.

2. **The Geometric Model (The Physicist's View)**:
   - A vector is an **arrow** pointing in space, originating from $(0,0)$.
   - A matrix is a **machine** that warps space. Imagine drawing a grid on a rubber sheet. A matrix stretches, squashes, or rotates that rubber sheet, keeping grid lines parallel and evenly spaced, and leaving the origin fixed.

3. **The Function Model (The Mathematician's View)**:
   - A matrix is a serialized representation of a **linear function**. Just as a JSON object serializes state, a matrix serializes a transformation. Matrix multiplication is not just multiplying numbers; it is **function composition** ($f(g(x))$).

4. **SVD as "Rotate, Stretch, Rotate"**:
   - Imagine a messy, skewed transformation. SVD says: instead of looking at the messy transformation all at once, you can decompose it into three simple steps: first rotate the space so it lines up with the axes, then stretch along the $x, y, z$ axes independently, then rotate the space to its final destination.

## 4. Intuitive Explanation (No Math Yet)

Let's walk through the core concepts using plain English and visual analogies.

### Scalars, Vectors, Matrices, and Tensors
Imagine you are describing the weather.
- The temperature is 72°F. That single number is a **scalar**.
- You want to describe the weather more fully: [72°F, 45% humidity, 12 mph wind]. This ordered list is a **vector**. It represents a point in a 3-dimensional "weather space".
- You record this 3-feature weather vector every day for 365 days. You now have a grid of numbers: 365 rows by 3 columns. This is a **matrix**.
- You record this matrix for 50 different cities. You now have a 3D block of data (50 cities $\times$ 365 days $\times$ 3 features). This is a **tensor** (specifically, a rank-3 tensor).

In LLMs, words are converted to vectors (embeddings). A sentence is a sequence of vectors (a matrix). A batch of sentences processed simultaneously is a 3D tensor: `(batch_size, sequence_length, embedding_dimension)`.

### Matrix Multiplication is Transformation
Suppose you have a 2D vector representing a point on a screen. You want to rotate that point by 90 degrees. You can construct a 2x2 matrix that acts as a "rotate 90 degrees" machine. When you feed your vector into this matrix (by multiplying them), the output is the new rotated vector.

If you want to scale the point by 2, and *then* rotate it, you could apply a scaling matrix, take the result, and apply the rotation matrix. Or, you can multiply the rotation matrix and the scaling matrix together to create a single "scale-then-rotate" matrix. **Matrix multiplication is just combining machines.**

### Inner Products and Norms
How long is an arrow? You measure it from the origin to its tip. This length is its **norm**.
How similar are two arrows? If they point in the exact same direction, they are highly aligned. If they are perpendicular (at a 90-degree angle), they share no direction. The **inner product** (or dot product) is a mathematical operation that takes two vectors and outputs a single scalar representing how aligned they are. This is the foundation of **attention** in LLMs: a query vector takes a dot product with a key vector to see how "aligned" or "relevant" they are to each other.

### Eigenvectors and Eigenvalues
Imagine you have a balloon, and you squish it in the middle while pulling the ends apart. Most points on the surface of the balloon move to entirely new angles from the center. However, the points exactly along the axis you are pulling move straight outward, and the points along the axis you are squishing move straight inward.

These special axes—where the transformation only stretches or shrinks, but does not rotate—are the **eigenvectors**. The amount of stretch or shrink along those axes are the **eigenvalues**.

### Singular Value Decomposition (SVD)
Not all transformations are as neat as pulling a balloon along a specific axis. Sometimes a matrix skews space drastically. SVD is a mathematical guarantee that *any* transformation, no matter how weird, can be broken down into three independent steps:
1. Spin the space (Rotation 1).
2. Stretch the space along the standard up/down/left/right axes (Scaling).
3. Spin the space again (Rotation 2).

The amounts by which we stretch the space in step 2 are called the **singular values**. If a singular value is 0, it means the matrix entirely flattens the space in that dimension (e.g., turning a 3D object into a 2D shadow).

## 5. Formal Definition and Notation

Let's introduce the standard notation used in machine learning papers.

- $\mathbb{R}$: The set of real numbers.
- **Scalar**: A lowercase letter, e.g., $c \in \mathbb{R}$.
- **Vector**: A bold lowercase letter, e.g., $\mathbf{x} \in \mathbb{R}^n$. It is an $n \times 1$ column vector:
  $$ \mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} $$
- **Matrix**: An uppercase letter, e.g., $A \in \mathbb{R}^{m \times n}$. It has $m$ rows and $n$ columns. The element in the $i$-th row and $j$-th column is denoted $A_{ij}$ or $a_{ij}$.
- **Tensor**: A bold uppercase or calligraphic letter, e.g., $\mathbf{T}$ or $\mathcal{T} \in \mathbb{R}^{d_1 \times d_2 \times \cdots \times d_k}$.

### Transpose
The transpose of a matrix $A$, denoted $A^\top$, swaps rows and columns: $(A^\top)_{ij} = A_{ji}$.
For a column vector $\mathbf{x}$, its transpose $\mathbf{x}^\top$ is a row vector: $\mathbf{x}^\top = [x_1, x_2, \dots, x_n]$.

### Matrix Operations
- **Addition**: $C = A + B$, where $C_{ij} = A_{ij} + B_{ij}$. Only defined if $A$ and $B$ have the exact same shape.
- **Multiplication**: For $A \in \mathbb{R}^{m \times p}$ and $B \in \mathbb{R}^{p \times n}$, the product $C = AB \in \mathbb{R}^{m \times n}$ is defined as:
  $$ C_{ij} = \sum_{k=1}^p A_{ik} B_{kj} $$
  The inner dimensions ($p$) must match.

### Inner Product (Dot Product)
The inner product of two vectors $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ is a scalar:
$$ \langle \mathbf{x}, \mathbf{y} \rangle = \mathbf{x}^\top \mathbf{y} = \sum_{i=1}^n x_i y_i $$

### Norms
The $L_p$ norm of a vector $\mathbf{x}$ is:
$$ \|\mathbf{x}\|_p = \left( \sum_{i=1}^n |x_i|^p \right)^{1/p} $$
- **L1 Norm** ($p=1$): Sum of absolute values. Promotes sparsity in machine learning.
- **L2 Norm** ($p=2$): Euclidean distance. $\|\mathbf{x}\|_2 = \sqrt{\mathbf{x}^\top \mathbf{x}}$. The standard measure of magnitude.
- **Frobenius Norm** for a matrix $A$: The square root of the sum of the absolute squares of its elements. $\|A\|_F = \sqrt{\sum_{i,j} A_{ij}^2}$.

### Identity, Inverse, and Orthogonality
- **Identity Matrix** $I$: A square matrix with 1s on the diagonal and 0s elsewhere. $AI = IA = A$.
- **Inverse** $A^{-1}$: For a square matrix $A$, if it exists, $A A^{-1} = A^{-1} A = I$.
- **Orthogonal Vectors**: $\mathbf{x}$ and $\mathbf{y}$ are orthogonal if $\mathbf{x}^\top \mathbf{y} = 0$.
- **Orthogonal Matrix**: A square matrix $Q$ whose columns and rows are orthogonal unit vectors. A crucial property is that $Q^\top Q = Q Q^\top = I$, which means $Q^{-1} = Q^\top$.

## 6. Deep Theoretical Treatment

### 6.1 Matrix Multiplication as Linear Combinations
The formula $C_{ij} = \sum_{k=1}^p A_{ik} B_{kj}$ is the "dot product of rows and columns" view. But a deeper, more useful view is the **column view**.

Consider a matrix $A$ multiplying a vector $\mathbf{x}$:
$$ A\mathbf{x} = \begin{bmatrix} | & | & & | \\ \mathbf{a}_1 & \mathbf{a}_2 & \dots & \mathbf{a}_n \\ | & | & & | \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} = x_1 \mathbf{a}_1 + x_2 \mathbf{a}_2 + \dots + x_n \mathbf{a}_n $$
$A\mathbf{x}$ is a **linear combination of the columns of $A$**, weighted by the elements of $\mathbf{x}$.

When multiplying two matrices $C = AB$, the $j$-th column of $C$ is simply the matrix $A$ multiplying the $j$-th column of $B$. Therefore, every column of $C$ is a linear combination of the columns of $A$.
This implies that the output of any matrix multiplication always lives in the **column space** (the space spanned by the columns) of the left matrix.

### 6.2 The Transpose Rule and Matrix Calculus
A foundational property you must memorize:
$$ (AB)^\top = B^\top A^\top $$
**Proof Sketch**:
Let $C = AB$. $C_{ij} = \sum_k A_{ik} B_{kj}$.
The transpose $(AB)^\top$ has $(j,i)$ entry $C_{ji} = \sum_k A_{jk} B_{ki}$.
Now look at $B^\top A^\top$. Its $(j,i)$ entry is the dot product of the $j$-th row of $B^\top$ and the $i$-th column of $A^\top$.
Row $j$ of $B^\top$ is column $j$ of $B$. Column $i$ of $A^\top$ is row $i$ of $A$.
So the term is $\sum_k (B^\top)_{jk} (A^\top)_{ki} = \sum_k B_{kj} A_{ik} = \sum_k A_{ik} B_{kj} = C_{ij}$. They match.

**Why this matters**: In backpropagation, if you have a layer $y = Wx$, the gradient of the loss $L$ with respect to $x$ is:
$$ \frac{\partial L}{\partial x} = W^\top \frac{\partial L}{\partial y} $$
The forward pass uses $W$, the backward pass uses $W^\top$. This falls directly out of the multivariable chain rule and the transpose identity.

### 6.3 Eigenvalues and Eigenvectors (The Spectral Theorem)
For a square matrix $A \in \mathbb{R}^{n \times n}$, an **eigenvector** $\mathbf{v}$ and its corresponding **eigenvalue** $\lambda$ satisfy:
$$ A\mathbf{v} = \lambda \mathbf{v} $$
(where $\mathbf{v} \neq \mathbf{0}$).
This means applying the matrix $A$ to $\mathbf{v}$ only scales it by $\lambda$; it doesn't change its direction.

**The Spectral Theorem**: If $A$ is a **real, symmetric** matrix ($A = A^\top$), then:
1. All of its eigenvalues are real numbers.
2. Its eigenvectors form an orthogonal basis for $\mathbb{R}^n$.
3. $A$ can be decomposed as $A = Q \Lambda Q^\top$, where $Q$ is an orthogonal matrix containing the eigenvectors, and $\Lambda$ is a diagonal matrix of eigenvalues.

Covariance matrices (e.g., $X^\top X$) are always symmetric and positive semi-definite (eigenvalues $\ge 0$). This theorem is why Principal Component Analysis (PCA) works perfectly.

### 6.4 Singular Value Decomposition (SVD)
Eigen-decomposition $A = Q\Lambda Q^\top$ only works for square, diagonalizable matrices. What if $A$ is rectangular ($m \times n$)?

**SVD Theorem**: *Every* matrix $A \in \mathbb{R}^{m \times n}$ can be factored as:
$$ A = U \Sigma V^\top $$
- $U \in \mathbb{R}^{m \times m}$ is an orthogonal matrix (its columns are the **left singular vectors**).
- $\Sigma \in \mathbb{R}^{m \times n}$ is a diagonal matrix containing the **singular values** $\sigma_i \ge 0$, usually sorted in descending order ($\sigma_1 \ge \sigma_2 \ge \dots \ge 0$).
- $V \in \mathbb{R}^{n \times n}$ is an orthogonal matrix (its columns are the **right singular vectors**).

**Intuition**: $V^\top$ rotates the input space. $\Sigma$ scales the axes. $U$ rotates the space into the output dimensions.

**The Eckart-Young-Mirsky Theorem**: If you want to approximate a matrix $A$ with a lower-rank matrix $A_k$ (where $k < \text{rank}(A)$) such that the difference $\|A - A_k\|_F$ is minimized, the *optimal* solution is to truncate the SVD.
Keep the top $k$ singular values in $\Sigma$, keep the first $k$ columns of $U$ and $V$, and multiply them:
$$ A \approx U_k \Sigma_k V_k^\top $$
This is the mathematical bedrock of data compression, PCA, and low-rank approximation (LoRA).

### 6.5 Edge Cases and Failure Modes
- **Singular Matrices**: A square matrix with a determinant of 0 cannot be inverted ($A^{-1}$ does not exist). Geometrically, it collapses space into a lower dimension. Computationally, trying to invert it will throw a `LinAlgError`.
- **Numerical Instability**: If a matrix is *nearly* singular (it has very small singular values relative to its large ones), it is "ill-conditioned". Inverting it or solving $Ax=b$ will blow up floating-point errors. This is why we often add a small identity matrix to the diagonal (Ridge regression/Tikhonov regularization: $(A^\top A + \lambda I)^{-1}$) to stabilize it.
- **Non-commutative**: A beginner mistake is writing $AB = BA$. Never assume this. Always preserve order when doing matrix algebra (e.g., expanding $(A+B)(A+B) = A^2 + AB + BA + B^2$).

## 7. Worked Examples

### Example 1: Matrix Multiplication by Hand
Let $A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$ and $B = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}$. Compute $C = AB$.

- $C_{11} = (1)(5) + (2)(7) = 5 + 14 = 19$
- $C_{12} = (1)(6) + (2)(8) = 6 + 16 = 22$
- $C_{21} = (3)(5) + (4)(7) = 15 + 28 = 43$
- $C_{22} = (3)(6) + (4)(8) = 18 + 32 = 50$

$$ C = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix} $$

### Example 2: Finding Eigenvalues
Let $A = \begin{bmatrix} 4 & 1 \\ 2 & 3 \end{bmatrix}$.
To find eigenvalues $\lambda$, we solve the characteristic equation $\det(A - \lambda I) = 0$.
$$ A - \lambda I = \begin{bmatrix} 4 - \lambda & 1 \\ 2 & 3 - \lambda \end{bmatrix} $$
Determinant is $(4 - \lambda)(3 - \lambda) - (1)(2) = 0$
$$ 12 - 4\lambda - 3\lambda + \lambda^2 - 2 = 0 $$
$$ \lambda^2 - 7\lambda + 10 = 0 $$
Factors into $(\lambda - 5)(\lambda - 2) = 0$.
The eigenvalues are $\lambda_1 = 5$ and $\lambda_2 = 2$.

### Example 3: SVD and Low-Rank Approximation in Python
Let's build a noisy matrix and use SVD to denoise it by keeping only the top components.

```python
import numpy as np

# Set print options for readability
np.set_printoptions(precision=2, suppress=True)

# Create a rank-1 matrix (signal)
u_true = np.array([[1, 2, 3]]).T
v_true = np.array([[4, 5, 6, 7]])
A_signal = u_true @ v_true # Shape (3, 4)

# Add random noise
np.random.seed(42)
A_noisy = A_signal + np.random.normal(0, 0.5, (3, 4))

print("Original Signal Matrix:")
print(A_signal)
print("\nNoisy Matrix:")
print(A_noisy)

# Compute full SVD
U, S, Vt = np.linalg.svd(A_noisy, full_matrices=False)
print("\nSingular Values:")
print(S)
# Expected: one large singular value (~14.7), two small ones from noise.

# Truncate to Rank-1 (keep k=1)
k = 1
U_k = U[:, :k]
S_k = np.diag(S[:k])
Vt_k = Vt[:k, :]

A_reconstructed = U_k @ S_k @ Vt_k

print("\nReconstructed Rank-1 Matrix (Denoised):")
print(A_reconstructed)
```
**Explanation**: The true matrix is strictly rank-1 (constructed by an outer product). The noise makes it rank-3. SVD reveals this structure: `S` will have one dominant value and two tiny ones. By reconstructing using only the top singular value ($k=1$), we effectively strip away the noise and recover a matrix very close to `A_signal`.

## 8. Connections to Machine Learning, Deep Learning, and LLMs

- **Transformer Attention**: The core equation is $A = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$.
  - $Q$ (Queries) and $K$ (Keys) are matrices of shape `(seq_len, d_k)`.
  - $QK^\top$ computes the dot product (inner product) between every query and every key simultaneously. The result is a `(seq_len, seq_len)` matrix of alignment scores.
- **Low-Rank Adaptation (LoRA)**: LLMs have massive weight matrices $W \in \mathbb{R}^{d_{in} \times d_{out}}$. Fine-tuning them entirely requires massive GPU RAM for gradients. LoRA freezes $W$ and learns an update $\Delta W = BA$, where $B \in \mathbb{R}^{d_{in} \times r}$ and $A \in \mathbb{R}^{r \times d_{out}}$. Because the rank $r$ is tiny (e.g., 16 vs 4096), you train drastically fewer parameters. The Eckart-Young theorem guarantees that this low-rank matrix can capture the most important directions of the ideal weight update.
- **Einsum**: In modern deep learning, especially multi-head attention where tensors are 4D `(batch, heads, seq, d_k)`, writing standard matrix multiplications requires confusing `reshape` and `transpose` calls. Einstein summation notation (`torch.einsum`) allows you to define tensor contractions explicitly using index labels (e.g., `einsum('bhqd, bhkd -> bhqk', Q, K)`), which is much less error-prone.

## 9. Practical Implementation

### NumPy vs PyTorch
The APIs are nearly identical for linear algebra.
- **Matrix Multiply**: `A @ B` (works in both).
- **Transpose**: `A.T` (both). For multi-dimensional tensors in PyTorch, use `tensor.transpose(dim0, dim1)`.
- **SVD**: `np.linalg.svd(A)` vs `torch.linalg.svd(A)`.
- **Eigenvalues**: `np.linalg.eig(A)` vs `torch.linalg.eig(A)`. For symmetric/Hermitian matrices (like covariance matrices), always use `eigh` instead of `eig`. It is faster and numerically stable, guaranteeing real outputs.

### Batched Matrix Multiplication (BMM)
In deep learning, you rarely multiply two 2D matrices. You multiply batches of matrices.
If $A$ is `(B, M, P)` and $B$ is `(B, P, N)`, the operation $A @ B$ in PyTorch performs a **batched matrix multiply**, resulting in `(B, M, N)`. The batch dimension `B` is treated independently.

### Numerical Stability Gotchas
- Never compute matrix inverse explicitly to solve a system ($x = A^{-1}b$). Always use `np.linalg.solve(A, b)` or `torch.linalg.solve(A, b)`. It uses LU decomposition under the hood, which is faster and avoids catastrophic precision loss.
- In `torch.linalg.svd`, gradients flowing through SVD can be unstable if singular values are identical or degenerate.

## 10. Advanced and Research Frontier

- **Randomized SVD**: Computing full SVD takes $O(m n^2)$ time. For massive matrices, we use randomized algorithms (Halko et al., 2011) that project the matrix onto a smaller random subspace, compute SVD there, and project back. It computes approximate top-$k$ singular values in a fraction of the time. This is implemented in `scikit-learn` as `TruncatedSVD`.
- **Tensor Decompositions**: SVD works for 2D matrices. For 3D+ tensors, there is no single generalization. Researchers use **CP Decomposition** or **Tucker Decomposition** to compress multi-dimensional neural network layers, though it is currently less popular than simple linear layers.
- **Hardware/Triton**: On GPUs, matrix multiplication is not done with nested for-loops. It is done via tiling, loading blocks into fast SRAM (shared memory), and utilizing specialized hardware (Tensor Cores). Writing custom Triton kernels (OpenAI) to fuse operations (like FlashAttention) requires understanding how matrix blocks map to GPU threads.

## 11. Common Mistakes, Misconceptions, and Anti-Patterns

1. **Assuming $AB = BA$**.
   *Mistake*: Reordering matrices in an equation freely.
   *Correction*: Matrix multiplication is not commutative. If $C = AB$, you cannot write $C = BA$.
2. **Confusing Element-wise Multiplication with Matrix Multiplication**.
   *Mistake*: Using `A * B` in NumPy/PyTorch when you meant `A @ B`.
   *Correction*: `*` is the Hadamard (element-wise) product. It multiplies elements at the exact same indices. `@` is the dot-product-based matrix multiplication.
3. **Taking the inverse of a non-square matrix**.
   *Mistake*: Calling `linalg.inv()` on a $5 \times 3$ matrix.
   *Correction*: Inverses only exist for square matrices. For rectangular systems, use the Moore-Penrose Pseudoinverse (`linalg.pinv()`) or least-squares (`linalg.lstsq()`).
4. **Getting lost in tensor dimensions during `.view()` or `.reshape()`**.
   *Mistake*: Using `.reshape()` to swap axes in PyTorch.
   *Correction*: `reshape` flattens data and reads it linearly. If you want to swap the "sequence" and "head" dimensions in an attention block, you MUST use `.transpose()` or `.permute()`.

## 12. Self-Assessment Questions

**Q1: What are the dimensions of $C$ if $A$ is $10 \times 5$ and $B$ is $5 \times 20$?**
<details>
<summary>Answer</summary>
$C$ is $10 \times 20$. The inner dimensions (5) collapse, leaving the outer dimensions.
</details>

**Q2: Prove that if an orthogonal matrix $Q$ rotates a vector $\mathbf{x}$, the L2 norm (length) of the vector does not change.**
<details>
<summary>Answer</summary>
The squared L2 norm of $\mathbf{x}$ is $\mathbf{x}^\top \mathbf{x}$.
Let $\mathbf{y} = Q\mathbf{x}$. The squared norm of $\mathbf{y}$ is $(Q\mathbf{x})^\top (Q\mathbf{x})$.
Using the transpose rule: $(Q\mathbf{x})^\top = \mathbf{x}^\top Q^\top$.
So, $\|\mathbf{y}\|_2^2 = \mathbf{x}^\top Q^\top Q \mathbf{x}$.
Since $Q$ is orthogonal, $Q^\top Q = I$.
Thus, $\mathbf{x}^\top I \mathbf{x} = \mathbf{x}^\top \mathbf{x} = \|\mathbf{x}\|_2^2$. The length is unchanged.
</details>

**Q3: In PyTorch, what is the difference between `A * B` and `A @ B`?**
<details>
<summary>Answer</summary>
`A * B` performs element-wise multiplication (Hadamard product), requiring `A` and `B` to have exactly the same shape (or be broadcastable). `A @ B` performs standard mathematical matrix multiplication.
</details>

**Q4: You have a matrix $M$ of shape `(1000, 1000)`. You apply SVD: $U, \Sigma, V^\top = \text{SVD}(M)$. You notice only the first 10 values in $\Sigma$ are non-zero. What does this mean?**
<details>
<summary>Answer</summary>
It means the matrix $M$ has a rank of 10. Even though it is a $1000 \times 1000$ matrix, all of its columns can be constructed as linear combinations of just 10 basis vectors. The space it transforms data into is only 10-dimensional, flat in the other 990 dimensions.
</details>

## 13. Glossary

- **Column Space**: The set of all possible vectors that can be formed by taking linear combinations of the columns of a matrix.
- **Diagonal Matrix**: A matrix where all entries outside the main diagonal are zero.
- **Eigenvalue / Eigenvector**: An eigenvector is a vector whose direction is unchanged by a matrix transformation. The eigenvalue is the scalar by which it is stretched.
- **Inner Product (Dot Product)**: The sum of the products of corresponding elements of two vectors. Measures alignment.
- **Norm**: A function that assigns a strictly positive length or size to each vector.
- **Orthogonal**: Perpendicular. The inner product is 0.
- **Rank**: The maximum number of linearly independent column vectors in a matrix.
- **Singular Value Decomposition (SVD)**: A factorization of any matrix into a rotation, a scaling, and a rotation.
- **Transpose**: Flipping a matrix over its diagonal.
